# Conditional docs

One line per feature doc in `app_docs/`, saying when to read it; read the lines whose situation matches your task.

- `app_docs/screens-and-components.md`: read when changing a component's props, a row's layout, a run row's phase label, the History card's fields, its branch text or its pull request link, a section heading, a colour, a timestamp's format, the page background, the sticky header, its z-index layer, the radio footer's layer, the floating Work with me button or the sidebar's sticky offset; when adding or removing `"use client"`; when changing the worker status widget or the sidebar's column layout.
- `app_docs/routing-and-navigation.md`: read when changing the route tree, the header's links, the Writing link or their current-section marking; when touching a project page's not-found decision or `generateStaticParams`.
- `app_docs/types.md`: read when changing `src/types/adw.ts`; when a database column is added, renamed or removed.
- `app_docs/data-boundary.md`: read when changing `src/data/index.ts`, a query key, the query client or a server prefetch; when adding a database read or an environment variable; when touching `getWorkers`.
- `app_docs/clock-and-prerender.md`: read when adding a time-dependent label or any `Date.now()`/`new Date()`; when a component ships as its Suspense fallback in the served HTML; when changing the worker store's poll.
- `app_docs/active-runs.md`: read when changing the Active entry, `getActiveRunsState`, `activeRunsQuery`, the three Active islands or the helpers in `src/lib/active-runs.ts`, or the failed-run window; when the sidebar's counts disagree with a project's Active section.
- `app_docs/project-page.md`: read when changing the project page's Active, Queue or History sections; when touching History's paging, its bookmark or its `?q` search; or which queue items the Queue section shows (the dependency hold).
- `app_docs/history-revalidation.md`: read when changing the `revalidateHistory` action, the `/api/revalidate` handler, a cache tag, `cacheLife` or `staleTimes`; when a completed run does not appear in History.
- `app_docs/error-and-loading-boundaries.md`: read when adding a `Suspense`, a `QueryBoundary`, a `SectionBoundary` or a loading fallback; when a failed read takes down more than its own section.
- `app_docs/realtime.md`: read when changing the `adw` channel, a Realtime reducer, the catch-up read, the runs cursor or the incremental catch-up, or the connection pill, the reconnect backoff or the channel's start delay; when a live update does not reach the screen.
- `app_docs/summary.md`: read when changing `/projects/log` (the daily log), its charts, its today card, its cache scopes or the sidebar's Daily log entry; when a day's totals look wrong.
- `app_docs/hire.md`: read when changing `/hire`, its form, the `sendHireRequest` action, `src/content/hire.ts`, the Turnstile or Resend configuration, the Work with me header button, the offer prompts or `?offer=`.
- `app_docs/home.md`: read when changing `/`, its copy in `src/content/home.ts`, `LOCATION` in `src/content/site.ts` or its two doors into `/hire`.
- `app_docs/writing.md`: read when adding or changing a post under `src/content/posts/`, the registry, `src/lib/posts.ts`, `/writing`, a post page, its Open Graph image, `src/mdx-components.tsx`, the post page's breadcrumb, the post page's minimap or the post metadata check (`yarn check:og`).
- `app_docs/analytics.md`: read when adding, renaming or removing a PostHog event, changing `instrumentation-client.ts`, `instrumentation.ts`, `src/lib/server-errors.ts`, `src/app/global-error.tsx`, an error boundary's reporting, the Realtime connection events or the PostHog annotation step of `.github/workflows/release.yml`, or touching the PostHog environment variables; when reading or adding a PostHog feature flag, calling `identify` or `reset`, changing the header's Login / Logout button; or tagging a device as internal (`?internal=`) or excluding automated browsers.
- `app_docs/changelog.md`: read when adding or changing a changelog entry under `src/content/changelog/`, its registry, `src/lib/changelog.ts`, `src/lib/changelog-backfill.ts`, `scripts/backfill-changelog.ts`, `scripts/release.ts`, `src/lib/release.ts`, `.github/workflows/release.yml`, `src/components/ChangelogStats.tsx` (the stats strip), `/projects/changelog` or the sidebar's Changelog entry; when touching release tags, GitHub Releases or the changelog draft pull request.
- `app_docs/radio.md`: read when changing the NTS radio footer, `src/components/RadioBar.tsx`, `src/lib/radio.ts`, the stream or credit URLs, `--radio-bar-height`, `FOOTER_LAYER`, the body's bottom padding or what renders after `main` in `src/app/layout.tsx`.
- `app_docs/ci.md`: read when changing `.github/workflows/ci.yml`, a CI step or its order, the Yarn or Playwright caches, their keys or how to bust them; when upgrading `@playwright/test`; when a CI run is slow or downloads browsers or system packages it should have cached.
